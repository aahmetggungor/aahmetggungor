## Çalışma biçimim

- **Çalıştırılabilir çıktı:** Kaynak kodu, örnek veri ve demoyu birlikte sunuyorum.
- **Ölçülebilir sonuç:** Etiketli verinin bulunduğu yerde metrik ve deney koşullarını açıkça yazıyorum.
- **Sınırları belirtme:** Etiketsiz kullanıcı videosuna doğruluk puanı vermiyorum; gizli veriler için yerel çalışma seçeneğini öne çıkarıyorum.

**Kullandığım araçlar:** Python, Streamlit, OpenCV, scikit-learn, JavaScript ve Git. Ayrıntılı kurulum adımları her projenin README dosyasında bulunuyor.

Bu depolar araştırma ve demo amaçlı prototiplerdir; gerçek afet, güvenlik veya mahremiyet kararları için üretim sistemi olarak sunulmuyorlar.
